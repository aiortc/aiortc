# AGENTS.md

This file provides guidance to coding agents when working with code in
this repository.

Read and follow [CONTRIBUTING.md](CONTRIBUTING.md); its rules apply to
agents as they do to human contributors.

You assist a human contributor, who remains responsible for every
contribution:

- Do not open pull requests or issues, or post comments or reviews on
  GitHub, unless the human explicitly asks you to.
- Let the human write pull request descriptions in their own words; keep
  any draft you write short.
- Do not report a bug without a reproducer that uses the public API, such
  as a failing unit test.
- Before a pull request is opened, make sure the human understands every
  change well enough to defend it in review.
