# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub
issues, discussions, or pull requests, and please do not email the
maintainers directly.

Instead, report them privately using GitHub's vulnerability reporting
form:

https://github.com/aiortc/aiortc/security/advisories/new

This ensures all maintainers are notified and lets us coordinate a fix
privately.

## What to include

To help us triage quickly, please include as much of the following as
you can:

- The affected version(s) or commit
- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept
- Any suggested mitigation or fix

## Supported versions

Security fixes are applied to the latest release only. Please verify
that the issue is present in the most recent version before reporting.

## What to expect

aiortc is maintained by volunteers. We will acknowledge your report
as soon as we can, keep you informed of our progress, and credit you
in the published advisory unless you prefer to remain anonymous.

We ask that you give us a reasonable amount of time to release a fix
before disclosing the issue publicly.
